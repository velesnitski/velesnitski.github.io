# ADR 0092: footer dots for /ascii and /space

Date: 2026-09-03
Status: accepted
Amends ADR 0089, closes the deferred-door notes in ADR 0090/0091.

## Context

/ascii and /space shipped without a homepage door; owner chose the
middot pattern for both: "lets add it as .dot in footer as other
products with ascii too".

## Decision

Two more invisible middots, identical styling, hover titles as the
only tell. Door order: rocket · fish · ascii · space · 🦕. The
triple-click © egg (ADR 0088) still leads to /fish.
