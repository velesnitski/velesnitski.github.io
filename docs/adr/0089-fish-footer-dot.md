# ADR 0089: second footer dot → /fish

Date: 2026-08-28
Status: accepted
Amends ADR 0088.

## Context

ADR 0088 gave /fish only the behavioral egg (triple-click the ©),
reasoning a third footer link would crowd the line. Owner wants the
middot pattern anyway: "link from main site, second 'dot'".

## Decision

A second invisible middot in the footer, styled identically to the
rocket's, between the rocket dot and the 🦕: rocket · fish · dino.
The triple-click egg stays — two doors to the same aquarium is in the
spirit of the site.
